Desligada

Seus leads ficam num Gist secreto da sua conta do GitHub. Faça isso uma vez em cada aparelho:

  1. Crie um token no GitHub (a opção gist já vem marcada). Em Expiration, escolha No expiration e clique em Generate token.
  2. Copie o código que começa com ghp_ e cole aqui embaixo. Use o mesmo token em todos os aparelhos.

Chave do Google não configurada

A busca pelo Google Maps traz avaliações, nota, telefone e site de cada empresa. Ela usa a API do Google Places, que tem uma cota gratuita mensal (dá para milhares de empresas por mês). Configure uma vez em cada aparelho:

  1. Entre no Google Cloud e crie um projeto (ex.: Radar de Leads). Ele pede um cartão para ativar o faturamento, mas a cota gratuita cobre o uso normal.
  2. Ative a “Places API (New)”.
  3. Em Credenciais, clique em Criar credenciais → Chave de API.
  4. Proteja a chave: em Restrições do aplicativo escolha Sites e adicione mende-debug.github.io/*. Em Restrições de API, marque só a Places API (New).
