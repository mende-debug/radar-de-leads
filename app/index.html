A busca pelo Google Maps traz avaliações, nota, telefone e site. Usa a Places API do Google, que tem cota gratuita mensal. A chave fica salva só neste aparelho.

  1. Crie um projeto no Google Cloud e ative o faturamento (a cota gratuita cobre o uso normal).
  2. Ative a Places API (New).
  3. Em Credenciais, clique em Criar credenciais → Chave de API.
  4. Proteja a chave: em Restrições do aplicativo escolha Sites e adicione mende-debug.github.io/*. Em Restrições de API, marque só a Places API (New). Cole a chave abaixo.
